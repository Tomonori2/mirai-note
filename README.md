# 未来ノート

これからの「お金」「準備」「からだ」を1か所で見るアプリです（旧名：つぎの暮らしノート）。会社員・公務員どちらでも使えます。

公開場所：https://tomonori2.github.io/mirai-note/

- **あと何日**：退職の日までのカウントダウン（未定のままでも使えます）
- **お金**：資産・生活費・年金・退職金などから「足りるかどうか（余白）」を計算。もうひとつの日（例：1年あと）とくらべることもできます
- **やること**：健康保険・年金・住民税など、退職の前後の手続きリスト
- **相談（AI）**：Gemini のキーを自分で入れると、仕組みの説明や考えの整理を手伝います（「辞めるべき」は決めません・投資のすすめはしません）
- **理想の1日**：退職したらどんな1日にしたいか。ホームの「きょうの ならし運転」で、できた日を1タップ記録できます（今週・30日の回数が出ます）
- **つづけた日数**：1日1つでも押すと連続日数がのび、最長記録も出ます。4週間のカレンダーで塗った日が見えます
- **きょうの一歩**：期限がいちばん近いやることを、ホームに1つだけ大きく出します
- **準備のみち**：やることが終わるたびに、コマが1マス進みます（ゴールは退職の日）
- **資産の記録**：月に1回、そのときの資産を入れると、計画とのズレとグラフの●で分かります
- **からだ**：つぎの暮らしの土台になる体の記録（下で説明）
- **ひとこと日記**：ホームで気分（😄😊😐😔😢）と1行だけ。「理想の1日」タブで読み返せ、その日のお酒・筋トレ・血圧も横に並びます。30日の気分のまとめと、飲まなかった日／飲んだ日の気分のくらべも出ます。カレンダーの日付からあとで書くこともできます。日記はAI相談には送りません
- **ごほうびカード**：続けた日数などの節目で、体と暮らしのひとことが書かれたカードが1枚ずつ増えます（全17枚・「理想の1日」タブ）

## からだ
- **筋トレのメニュー**：「家で・道具なし」「ジムで・はじめて（マシン）」「ジムで・なれている人」の3コース。やった日に「きょうやった」を押すと今週の回数が出ます
- **重さと回数の記録**：重さ×回数から「1回だけ挙がりそうな重さ」の目安を出し（12回まで）、自己ベストを更新するとお知らせします
- **血圧・体重**：血圧は朝と夜の2回を記録できます。グラフと直近7日の平均（朝・夜べつ）。家庭血圧の目安（上135・下85）の線を引きます。病気の判断はしません
- **病院に見せる記録**：直近4週間の平均・グラフ・毎日の記録を1枚にまとめ、画像か印刷・PDFにできます（血圧手帳の代わりに）
- 筋トレの種目を入れると、**前回の記録**（重さ×回数）が出ます
- 筋トレは「この1週間」の日付を押すと、**押し忘れた日もあとから記録**できます
- 血圧といっしょに**脈拍**も記録できます（病院に見せる記録にも載ります）
- ホームの「からだ」カードから、**筋トレ・お酒は1タップで記録**、血圧は入力欄へ直接飛べます
- **お酒なしの日数**（使いたい人だけ）：毎日「🍵飲まなかった／🍺飲んだ」を1タップ（ホームからも）。続いている日数・浮いたお金・節目のバッジが出ます。押し忘れた日は「飲まなかった」扱いなので、連続日数は途切れません
- **お酒のカレンダー**：ひと月ぶんを🍵・🍺・空白で並べます。日付を押すと記録を直せます。3か月で3回以上飲んだら、飲んだ日が多い曜日も出ます
- **おつかれの日**：夜勤明けや寝不足の日は、ホームの「きょうは おつかれの日」を押すと、軽いメニュー（仮眠・散歩・水分・早寝）に切りかわります。ひとつできれば連続日数はつながります

## よくある質問

**いまの給与はどこに入れるの？**
聞きたいことによって3つあります。

- いま働いている給与 → 「まずはこれだけ」の**いまの手取り（ひと月）**。退職の日までに貯まるお金を計算します
- もう少し働いたらどうなるかを見る → 「もうひとつの日とくらべる」の**働いている間の給与など（手取り・1年あたり）**（空なら上の手取り×12を使います）
- 辞めたあとも働いて収入がある → 「くわしく入れる」の**退職後に働いて得るお金**

「お金」タブの上にある「いまの給与（お給料・ボーナス）はどこに入れる？」を開くと、それぞれの欄へ飛べます。

## 家族に見せるまとめ
「お金」タブ（またはホームの「お金の余白」）の **📄 家族に見せるまとめ** から、数字・グラフ・やることを1枚にまとめられます。
- **画像にする**：Androidなら、そのままLINEなどで送れます。iPhoneは画像を長押しして保存します
- **印刷・PDFで保存**：紙に出して話し合うときに
- お金の数字がすべて入っているので、送るのは家族だけにしてください

## 使い勝手
- 「右上の⚙設定 → 文字の大きさ」で、**ふつう／大きい／とても大きい** を選べます
- 数字が大きすぎる・小さすぎるとき（年の額をひと月の欄に入れた、など）は、欄の下に**やんわり注意**が出ます
- 誕生月（ねんきん定期便が届く月）には、ホームに**数字を見直す案内**が出ます
- やることは「**よくあるやることから選ぶ**」で、期限の目安つきで足せます
- 生活費は **いまの生活費**（退職の日までに貯まるお金の計算に使う）と **退職後の生活費** に分けて入れられます。いまの生活費が空なら、退職後と同じとして計算します
- どちらも「**内訳から計算する**」を開くと、住まい・食費・光熱費など12の項目ごとに入れられます（合計が自動で入ります。全部消すと、前に入れていた額に戻ります）。退職後の内訳は「**いまの内訳を写す**」で写してから、変わる項目だけ直せます
- 退職後も働くときは、「くわしく入れる」の **退職後の働き方** に最大3つまで入れられます（例：60〜65歳は再雇用で月20万円、65〜70歳はパートで月8万円）。年金が始まったあとの収入も数えます
- 年金の欄には **65歳から受け取る場合の見込み額** を入れます。70歳からなど受け取る年齢を変えると、増える・減る分を自動で計算します
- 夫婦で年金の始まる時期がずれるときは、「くわしく入れる」で**配偶者の年金を分けて**入れられます
- 親への仕送りや介護の手伝いがあるときは、「くわしく入れる」で**親のために出るお金**（ひと月・何年・何歳から）を入れられます。よくあるやることにも、親の見守りの準備（地域包括支援センターを調べる など）があります
- 押し忘れた日は、カレンダーの日をタップすると**あとから記録**できます
- やることは ✎ から**文と期限を直せます**
- スマホが夜モードなら、**自動で暗い色**になります
- 「右上の⚙設定 → 記録を全部消す」で、はじめの状態に戻せます

## データについて
- 入れた数字や記録は**この端末の中だけ**に保存されます。作った人にも送られません。
- 「相談」で「自分の数字も伝える」にチェックしたときだけ、その内容が Google（Gemini）に送られます。
- ブラウザの掃除や機種変更で消えるので、「右上の⚙設定 → データの控え」でときどき控えを取ってください。
- 計算は入れた数字の足し算・引き算だけです。制度の細かいところは勤め先・年金事務所・市区町村などで確かめてください。
