# つぎの暮らしノート

退職の前後の「お金」と「準備」を1か所で見るアプリです。会社員・公務員どちらでも使えます。

- **あと何日**：退職の日までのカウントダウン（未定のままでも使えます）
- **お金**：資産・生活費・年金・退職金などから「足りるかどうか（余白）」を計算。もうひとつの日（例：1年あと）とくらべることもできます
- **やること**：健康保険・年金・住民税など、退職の前後の手続きリスト
- **相談（AI）**：Gemini のキーを自分で入れると、仕組みの説明や考えの整理を手伝います（「辞めるべき」は決めません・投資のすすめはしません）
- **理想の1日**：退職したらどんな1日にしたいか。ホームの「きょうの ならし運転」で、できた日を1タップ記録できます（今週・30日の回数が出ます）
- **つづけた日数**：1日1つでも押すと連続日数がのび、最長記録も出ます。4週間のカレンダーで塗った日が見えます
- **きょうの一歩**：期限がいちばん近いやることを、ホームに1つだけ大きく出します
- **準備のみち**：やることが終わるたびに、コマが1マス進みます（ゴールは退職の日）
- **資産の記録**：月に1回、そのときの資産を入れると、計画とのズレとグラフの●で分かります

## よくある質問

**いまの給与はどこに入れるの？**
聞きたいことによって3つあります。

- いま働いている給与 → 「まずはこれだけ」の**いまの手取り（ひと月）**。退職の日までに貯まるお金を計算します
- もう少し働いたらどうなるかを見る → 「もうひとつの日とくらべる」の**働いている間の給与など（手取り・1年あたり）**（空なら上の手取り×12を使います）
- 辞めたあとも働いて収入がある → 「くわしく入れる」の**退職後に働いて得るお金**

「お金」タブの上にある「いまの給与（お給料・ボーナス）はどこに入れる？」を開くと、それぞれの欄へ飛べます。

## 家族に見せるまとめ
「お金」タブ（またはホームの「お金の余白」）の **📄 家族に見せるまとめ** から、数字・グラフ・やることを1枚にまとめられます。
- **画像にする**：Androidなら、そのままLINEなどで送れます。iPhoneは画像を長押しして保存します
- **印刷・PDFで保存**：紙に出して話し合うときに
- お金の数字がすべて入っているので、送るのは家族だけにしてください

## 使い勝手
- 「右上の⚙設定 → 文字の大きさ」で、**ふつう／大きい／とても大きい** を選べます
- 数字が大きすぎる・小さすぎるとき（年の額をひと月の欄に入れた、など）は、欄の下に**やんわり注意**が出ます
- 誕生月（ねんきん定期便が届く月）には、ホームに**数字を見直す案内**が出ます
- やることは「**よくあるやることから選ぶ**」で、期限の目安つきで足せます
- 夫婦で年金の始まる時期がずれるときは、「くわしく入れる」で**配偶者の年金を分けて**入れられます
- 押し忘れた日は、カレンダーの日をタップすると**あとから記録**できます
- やることは ✎ から**文と期限を直せます**
- スマホが夜モードなら、**自動で暗い色**になります
- 「右上の⚙設定 → 記録を全部消す」で、はじめの状態に戻せます

## データについて
- 入れた数字や記録は**この端末の中だけ**に保存されます。作った人にも送られません。
- 「相談」で「自分の数字も伝える」にチェックしたときだけ、その内容が Google（Gemini）に送られます。
- ブラウザの掃除や機種変更で消えるので、「右上の⚙設定 → データの控え」でときどき控えを取ってください。
- 計算は入れた数字の足し算・引き算だけです。制度の細かいところは勤め先・年金事務所・市区町村などで確かめてください。
