退職の前後のお金と準備を、1か所で見るノートです。
この順に進むと、3分くらいで形になります。
  1. 退職の日を入れる（右上の「⚙設定」）。決まっていなければ「未定」のままで大丈夫です
  2. お金の数字を入れる（「お金」）。生まれた年月・資産・手取り・生活費の4つから始められます
  3. やることを見る。健康保険や年金の手続きが、期限つきで入っています
  4. 毎日はホームだけ見ればOK。「きょうの一歩」と「ならし運転」を押すだけです
🔒 入れた数字や記録は、この端末の中だけに保存されます。作った人にも、だれにも送られません（「相談」でAIに送ると決めたときだけ、Googleに送ります）。

いまの給与（お給料・ボーナス）はどこに入れる？
給与を入れる場所は、聞きたいことによって3つあります。
① いま働いている給与 → すぐ下の「いまの手取り（ひと月）」。退職の日までに貯まるお金を計算します。
② もう少し働いたらどうなるかを見たいとき → 下の「もうひとつの日とくらべる」の「働いている間の給与など（手取り・1年あたり）」（空のままなら①の手取り×12で計算します）
③ 辞めたあとも働いて収入があるとき → 「くわしく入れる」の「退職後に働いて得るお金」

退職の相談（AI）

年金・健康保険・退職金の仕組みや、迷っていることの整理を手伝います。「辞めるべき」は決めません。考える材料と、確かめる先をお返しします。
使うには「キー」が要ります（無料・3分）
AIに聞くには、Google の Gemini という道具のキー（合いカギのような文字）が要ります。無料で取れます。キーが無くても、ほかの画面はすべて使えます。
  1. Google AI Studio を開き、Googleアカウントでログインします
  2. 「APIキーを作成（Create API key）」を押します
  3. 出てきた AIza… で始まる文字をコピーします
  4. このアプリの右上の「⚙設定」→「AI相談のキー」に貼って保存します
キーは、この端末の中だけに保存されます。ほかの人には見えません。
無料のキーでは、送った内容がGoogleのサービス改善に使われることがあります。伝えたくなければチェックを外したままにしてください。

毎日つかう道具なので、ホーム画面に置いておくと1タップで開けます。ブラウザの掃除で記録が消えにくくもなります。

    
やり方
      
Android（Chrome）：右上の ⋮ →「ホーム画面に追加」

      
iPhone（Safari）：下の □↑（共有）→「ホーム画面に追加」

      
※ GoogleアプリやLINEの中のブラウザでは出ません。ChromeかSafariで開いてください。
